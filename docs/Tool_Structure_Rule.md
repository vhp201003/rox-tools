# CenNext Workspace - Tool Architecture & Build Specification Rule

> **Mandatory code structure, modular architecture, and distribution pipeline rules for all browser bookmarklets, extensions, and automation tools across CenNext Workspace.**

---

## 1. Rule Overview & Mandatory Requirements

To ensure long-term maintainability, rapid debugging, and seamless distribution across projects, all current and future tools must adhere strictly to the following standards:

1. **No Monolithic Single-File Source**:
   - Source code must **never** be developed as a single massive `.js` file.
   - Core application logic must be decomposed into modular files under `src/`, with clear separation of concerns (Configuration, Authentication, Networking, UI Rendering, and Bootstrapping).
2. **Automated Zero-Dependency Build Pipeline (`build.js`)**:
   - Every tool project must include a standalone Node.js compilation script (`build.js`) using native `fs` and `path` modules (no heavy bundler configuration like Webpack or Vite required for bookmarklet tools).
3. **Standard Distribution Artifacts (`dist/`)**:
   - Running `node build.js` must deterministically compile and output three standard distribution files:
     - **`dist/bundle.js`**: Clean, unminified concatenated bundle wrapped in an IIFE for DevTools console debugging.
     - **`dist/bookmarklet.js`**: Minified, single-line `javascript:(function(){...})();` string ready for manual bookmark URL editing.
     - **`dist/bookmarklet.html`**: Netscape Bookmark format file enabling instant drag-and-drop installation into the browser bookmarks bar.
4. **Adherence to Design System**:
   - The UI module (`src/ui.js`) must strictly conform to the **Obsidian-Slate Design System** defined in [docs/Design.md](file:///D:/CenNextWorkSpace/docs/Design.md) (Zero UI Icons, High-density typography, Vertical Navigation Rail).

## 2. Standard Project Directory Structure

Every tool repository or workspace subfolder must mirror this canonical structure:

```
[Tool_Directory_Name]/
├── src/                         # Modular Source Code (Strictly segregated)
│   ├── config.js                # App constants, endpoints, selectors, storage keys
│   ├── queries.js (or .graphql) # API queries, GraphQL schemas, or REST endpoint templates
│   ├── auth.js (if applicable)  # Session sniffer, bearer token resolver, cache cleanup
│   ├── api.js                   # Batch fetch, sub-chunking, concurrency, aggregation engine
│   ├── ui.js                    # DOM creation, event listeners, table rendering, TSV exports
│   └── index.js                 # Application bootstrapper & entry point
├── dist/                        # Compiled Distribution Artifacts (Generated by build.js)
│   ├── bundle.js                # Unminified combined bundle for F12 Console debugging
│   ├── bookmarklet.js           # Minified single-line bookmarklet payload
│   └── bookmarklet.html         # Netscape Drag-and-Drop bookmark installer
├── build.js                     # Automated bundling & distribution compiler
└── README.md                    # Technical documentation, features, and usage guide
```

## 3. Module Responsibility Matrix (`src/`)

| File | Primary Responsibility | Strict Rules & Boundaries |
| :--- | :--- | :--- |
| **`src/config.js`** | Single source of truth for constants. | Declare endpoints, batch sizes, storage keys, modal element IDs, and default parameters. **No DOM manipulation or network calls.** |
| **`src/queries.js`** | API request payloads and schemas. | Export GraphQL query strings, REST payload builders, or URL query formatters. |
| **`src/auth.js`** | Authentication & session management. | Token extraction, session cookie verification, local cache handling (`sessionStorage` / `localStorage`), and 401 re-authentication flow. |
| **`src/api.js`** | Network execution & data pipeline. | Batch chunking (e.g. 50 items/batch), retry logic, sub-query orchestration, and data transformation/aggregation. |
| **`src/ui.js`** | View layer & user interaction. | Inject modal shell, draggable header, vertical nav rail, search/input bindings, data table rendering, status updates, and TSV clipboard copy. Must follow [docs/Design.md](file:///D:/CenNextWorkSpace/docs/Design.md). |
| **`src/index.js`** | Entrypoint orchestrator. | Check runtime conditions (e.g. host domain validation), wire API events to UI handlers, and trigger initial mount. |

## 4. Canonical Build Script Template (`build.js`)

Copy and adapt this standardized build script in each project root:

```javascript
// ==========================================================================
// CenNext Standard Tool Compiler & Bundler (build.js)
// ==========================================================================

const fs = require('fs');
const path = require('path');

// 1. Resolve Directories
const srcDir = path.join(__dirname, 'src');
const distDir = path.join(__dirname, 'dist');

if (!fs.existsSync(distDir)) {
    fs.mkdirSync(distDir, { recursive: true });
}

// 2. Define Execution Order of Modules
// NOTE: Adjust array items to match your tool's specific modules in src/
const modules = [
    'config.js',
    'queries.js',
    'auth.js',
    'api.js',
    'ui.js',
    'index.js'
];

// Configuration for Tool Name in Bookmarks
const TOOL_DISPLAY_NAME = 'CenNext Tool Name';

// 3. Assemble Raw Bundle (Wrapped in isolated IIFE)
let rawBundle = '(function () {\n';
rawBundle += '  "use strict";\n\n';

for (const file of modules) {
    const filePath = path.join(srcDir, file);
    if (fs.existsSync(filePath)) {
        rawBundle += `  // --- Module: ${file} ---\n`;
        rawBundle += fs.readFileSync(filePath, 'utf8') + '\n\n';
    }
}
rawBundle += '})();\n';

// 4. Output Unminified Bundle (for Console / Debugging)
fs.writeFileSync(path.join(distDir, 'bundle.js'), rawBundle, 'utf8');
console.log('✅ Generated dist/bundle.js');

// 5. Minify for Bookmarklet
function minifyJs(code) {
    return code
        .replace(/\/\*[\s\S]*?\*\/|([^:]|^)\/\/.*$/gm, '$1') // Strip single & multi-line comments
        .replace(/\n\s*/g, ' ')                              // Collapse newlines and whitespace
        .replace(/\s{2,}/g, ' ')                             // Collapse multiple spaces
        .trim();
}

const minifiedCode = 'javascript:' + minifyJs(rawBundle);
fs.writeFileSync(path.join(distDir, 'bookmarklet.js'), minifiedCode, 'utf8');
console.log(`✅ Generated dist/bookmarklet.js (${minifiedCode.length} chars)`);

// 6. Generate Netscape Bookmark File (bookmarklet.html)
function escapeHtmlAttr(str) {
    return str
        .replace(/&/g, '&amp;')
        .replace(/"/g, '&quot;')
        .replace(/'/g, '&#39;')
        .replace(/</g, '&lt;')
        .replace(/>/g, '&gt;');
}

const nowUnix = Math.floor(Date.now() / 1000);
const netscapeBookmarkHtml = `<!DOCTYPE NETSCAPE-Bookmark-file-1>
<!-- This is an automatically generated file.
     It will be read and overwritten.
     DO NOT EDIT! -->
<META HTTP-EQUIV="Content-Type" CONTENT="text/html; charset=UTF-8">
<TITLE>Bookmarks</TITLE>
<H1>Bookmarks</H1>
<DL><p>
    <DT><H3 ADD_DATE="${nowUnix}" LAST_MODIFIED="${nowUnix}" PERSONAL_TOOLBAR_FOLDER="true">Bookmarks bar</H3>
    <DL><p>
        <DT><A HREF="${escapeHtmlAttr(minifiedCode)}" ADD_DATE="${nowUnix}">${TOOL_DISPLAY_NAME}</A>
    </DL><p>
</DL><p>
`;

fs.writeFileSync(path.join(distDir, 'bookmarklet.html'), netscapeBookmarkHtml, 'utf8');
console.log(`✅ Generated dist/bookmarklet.html (${netscapeBookmarkHtml.length} bytes)`);
console.log('🎉 Tool Build Completed Successfully!');
```

## 5. Distribution Artifacts & Installation UX

Every tool must support three standardized installation and execution methods:

### Method 1: Drag-and-Drop via `bookmarklet.html` (Recommended for End-Users)
1. Open `dist/bookmarklet.html` directly in Google Chrome or Microsoft Edge.
2. Ensure the Bookmarks bar is visible (`Ctrl + Shift + B` on Windows / `Cmd + Shift + B` on macOS).
3. Click and drag the link titled with the tool name directly onto the browser's Bookmarks bar.
4. Navigate to the target portal and click the bookmark to run.

### Method 2: Browser Bookmark Import (Alternative for Non-Technical Users)
1. In Chrome or Edge, navigate to **Settings** → **Bookmarks** → **Import Bookmarks and Settings**.
2. Select **Bookmarks HTML File** from the dropdown and select `dist/bookmarklet.html`.
3. The bookmarklet appears immediately in the Bookmarks bar folder.

### Method 3: Developer Console Injection (For QA & Development)
1. Open `dist/bundle.js`.
2. Open DevTools Console (`F12`) on the target web page.
3. Paste the entire content and press `Enter` to run the tool with unminified debug logs.

## 6. Development Workflow & Validation Checklist

Before marking any tool task as complete:

- [ ] **No Monolithic JS**: Confirm logic is split across `src/` modules (`config.js`, `api.js`, `ui.js`, `index.js`).
- [ ] **Clean Build**: Run `node build.js` and verify zero compiler errors.
- [ ] **All 3 Artifacts Present**: Confirm `dist/bundle.js`, `dist/bookmarklet.js`, and `dist/bookmarklet.html` are generated and up-to-date.
- [ ] **Zero UI Icons in `src/ui.js`**: Verify strict compliance with the typography-driven Obsidian-Slate system (no SVG icons, no external icon fonts).
- [ ] **HTML Sanitization**: Ensure all dynamic strings rendered in `src/ui.js` use `escapeHtml()` to avoid DOM XSS.
- [ ] **Direct TSV Export**: Ensure copy button exports TSV formatted data (`\t` separated) for Google Sheets / Excel.
